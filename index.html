    Static Index

    The registry stores plain files. Your CLI reads them from https://registry.htpl.hvcrealm.com. No request hits a database.

    Static Index Files
    File or CommandWhat It Does
    index.jsonLists every gadget: description, owner, repo, latest version, and its file.
    gadgets/<name>.jsonLists one gadget: all versions, tarball URL, SHA-256 hash, signature, and yanked state.
    htpl pm install <name>Reads gadgets/<name>.json only. It verifies the tarball hash before it installs.
    htpl pm search <query>Reads index.json and filters the list on your machine.
